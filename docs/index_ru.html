MakeACopy

MakeACopy — это приложение для сканирования документов с открытым исходным кодом для Android, которое позволяет оцифровывать бумажные документы с функцией OCR. Приложение разработано с учетом конфиденциальности, работает полностью оффлайн без подключения к облаку или отслеживания.

Возможности

  • Сканирование камерой: Снимайте документы с помощью камеры устройства
  • Обнаружение краев: Автоматическое определение краев документа с использованием OpenCV
  • Коррекция перспективы: Настройка и обрезка документов с ручной или автоматической коррекцией перспективы
  • Улучшение изображения: Применение фильтров (оттенки серого, контраст, резкость)
  • OCR: Офлайн-распознавание текста с помощью Tesseract
  • Экспорт в PDF: Сохранение в виде поискового PDF с распознанным текстом
  • Поделиться и сохранить: Локальный экспорт или обмен с другими приложениями
  • Темный режим: Тема Material 3 с поддержкой дня и ночи
  • Конфиденциальность: 100% оффлайн-функциональность, не требуется подключение к интернету

Как использовать

  1. Сканировать документ: Откройте приложение и нажмите кнопку сканирования для съемки документа
  2. Настроить углы: Точно отрегулируйте обнаруженные края документа
  3. Обрезать и улучшить: Примените обрезку и улучшение изображения при необходимости
  4. Обработка OCR: Приложение распознает текст в документе
  5. Экспорт и обмен: Сохраните в PDF или поделитесь с другими приложениями

Конфиденциальность

MakeACopy разработан с учетом конфиденциальности:

  • Не требуется подключение к интернету
  • Нет запросов к серверам или телеметрии
  • Обработка OCR происходит локально на вашем устройстве
  • Требуемые разрешения: Камера, Хранение файлов
  • Нет подключений к третьим сторонам

Для подробностей смотрите нашу Политику конфиденциальности.
