# MakeACopy

MakeACopy — это приложение для сканирования документов с открытым исходным кодом для Android, которое позволяет оцифровывать бумажные документы с функцией OCR. Приложение разработано с учетом конфиденциальности и работает полностью офлайн — без подключения к облаку и без отслеживания.

[![Получить в Google Play](https://play.google.com/intl/en_us/badges/images/generic/en-play-badge.png)](https://play.google.com/store/apps/details?id=de.schliweb.makeacopy)

Или загрузите последнюю версию APK из [раздела релизов](https://github.com/egdels/makeacopy/releases/latest).

[![Лицензия](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## Особенности

- **Сканирование камерой**: съемка документов с помощью камеры устройства  
- **Обнаружение краев**: автоматическое определение границ документа с использованием OpenCV  
- **Коррекция перспективы**: ручная или автоматическая настройка и обрезка документов  
- **Улучшение изображения**: применение фильтров (оттенки серого, контраст, резкость)  
- **OCR**: офлайн-распознавание текста с помощью Tesseract  
- **Экспорт в PDF**: сохранение в виде поисковых PDF с распознанным текстом  
- **Поделиться и сохранить**: экспорт локально или обмен через другие приложения  
- **Темный режим**: тема Material 3 с поддержкой светлого и темного оформления  
- **Ориентировано на конфиденциальность**: 100% офлайн, не требуется подключение к интернету

## Установка

### F-Droid

MakeACopy соответствует требованиям F-Droid и скоро будет доступен в магазине F-Droid. Приложение использует двухэтапный подход для интеграции OpenCV:

1. **Java-классы**: модуль OpenCV в репозитории предварительно очищен от всех бинарных файлов и содержит только необходимые Java-классы.  
2. **Нативные библиотеки**: все нативные библиотеки собираются из исходников во время процесса сборки, используя официальный исходный код OpenCV с https://github.com/opencv/opencv.git.

Такой подход обеспечивает совместимость с F-Droid, исключая предсобранные бинарники из репозитория и строя все нативные компоненты из исходников.

### Релизы на GitHub

Скачивайте последнюю версию APK на странице [релизов](https://github.com/egdels/makeacopy/releases).

#### Автоматизированные сборки

В проекте есть два workflow на GitHub для автоматических сборок:

##### Сборки релизов

Автоматически собирает APK и AAB при создании нового тега:

1. Создайте тег, начинающийся с 'v' (например, `v1.0.0`)  
2. Отправьте тег на GitHub  
3. Workflow автоматически:  
   - Настроит JDK 21 и Android NDK 29.0.13599879  
   - Скачает исходники OpenCV  
   - Соберет нативные библиотеки OpenCV для всех архитектур  
   - Интегрирует нативные библиотеки в приложение  
   - Соберет Debug APK, Release APK (без подписи) и Android App Bundle (AAB)  
4. Артефакты будут добавлены в релиз на GitHub

Обеспечивает 100% совместимость с F-Droid.

##### Сборки для интеграции OpenCV

Собирает приложение при каждом пуше в ветку main и Pull Request:

1. Настроит JDK 21 и Android NDK 29.0.13599879  
2. Скачает исходники OpenCV  
3. Соберет нативные библиотеки для всех архитектур  
4. Интегрирует их в приложение  
5. Соберет приложение с интегрированными библиотеками  
6. Загрузит собранный APK как артефакт

Это обеспечивает тестирование интеграции при каждом изменении кода.

### Сборка из исходников

1. Клонируйте репозиторий:  
    ```
    git clone https://github.com/egdels/makeacopy.git
    ```
2. Процесс сборки автоматически:  
   - Скачает исходники OpenCV  
   - Соберет нативные библиотеки для всех архитектур  
   - Интегрирует библиотеки в приложение  

   Для этого используются Gradle-задачи, вызывающие скрипты:  
   - `scripts/fetch_opencv.sh`  
   - `scripts/build_opencv_android.sh`  
   - `scripts/prepare_opencv.sh`  

3. Соберите приложение с помощью Gradle:  
    ```
    ./gradlew assembleDebug
    ```
4. Установите сгенерированный APK на устройство.

> **Примечание по совместимости с F-Droid**: проект 100% совместим с F-Droid за счет двухэтапного подхода: Java-классы OpenCV предварительно очищены от бинарников, все нативные библиотеки строятся из исходников.

#### Настройка Android NDK

1. Установите NDK через Android Studio:  
   - Откройте Android Studio → Настройки → Appearance & Behavior → System Settings → Android SDK  
   - Перейдите на вкладку 'SDK Tools'  
   - Отметьте 'NDK (Side by side)' и примените

2. Опционно настройте переменную окружения ANDROID_NDK_HOME:  
   - Скрипт пытается найти NDK автоматически  
   - При необходимости задайте вручную  
     ```
     # Linux/macOS
     export ANDROID_NDK_HOME=/путь/до/android-sdk/ndk/29.0.13599879

     # Windows (Command Prompt)
     set ANDROID_NDK_HOME=C:\путь\до\android-sdk\ndk\29.0.13599879

     # Windows (PowerShell)
     $env:ANDROID_NDK_HOME="C:\путь\до\android-sdk\ndk\29.0.13599879"
     ```

#### Поддержка интеграции OpenCV

Интеграция использует двухэтапный подход:

- Java-классы: модуль OpenCV предварительно очищен  
- Нативные библиотеки: собираются из исходников

Для обновления:

##### Обновление Java-классов (модуля OpenCV)

1. Скачайте новую версию Android SDK OpenCV [с сайта OpenCV](https://opencv.org/releases/)  
2. Замените папку `opencv` в репозитории на новую `sdk` из скачанного SDK  
3. Запустите скрипт очистки бинарников:  
    ```
    ./scripts/clean_opencv_binaries.sh
    ```
4. Зафиксируйте изменения в репозитории:  
    ```
    git add opencv
    git commit -m "Обновление модуля OpenCV до версии X.Y.Z (предварительно очищен)"
    ```

##### Обновление процесса сборки нативных библиотек

1. Обновите версию OpenCV в `scripts/fetch_opencv.sh`  
2. Проверьте сборку:  
    ```
    ./gradlew clean assembleDebug
    ```
3. Обновите версии в `app/build.gradle` и документации

## Использование

1. **Сканируйте документ**: откройте приложение и нажмите кнопку сканирования  
2. **Настраивайте углы**: отрегулируйте края документа  
3. **Обрезайте и улучшайте** изображение  
4. **Обрабатывайте OCR**: приложение распознает текст  
5. **Экспортируйте и делитесь** в PDF или через другие приложения

## Архитектура

MakeACopy использует архитектуру Single-Activity + Multi-Fragment в стиле MVVM. Основные компоненты:

- **Фрагмент камеры**: съемка документов через CameraX/Camera2 API  
- **Фрагмент обрезки**: детекция краев и коррекция перспективы  
- **Фрагмент OCR**: распознавание текста через Tesseract  
- **Фрагмент экспорта**: создание и обмен PDF

## Используемые библиотеки

| Назначение         | Библиотека               | Лицензия   |
|--------------------|--------------------------|------------|
| Обработка изображений | OpenCV для Android      | Apache 2.0 |
| OCR                 | tess-two (Tesseract JNI) | Apache 2.0 |
| PDF                 | Android PdfDocument       | Apache 2.0 |
| UI                  | Material Components       | Apache 2.0 |

## Конфиденциальность

MakeACopy разработан с учетом конфиденциальности:

- Не требует интернета  
- Нет серверных запросов и телеметрии  
- OCR происходит локально на устройстве  
- Необходимые разрешения: Камера, Файловое хранилище  
- Нет подключения к сторонним сервисам

Подробнее см. в [Политике конфиденциальности](https://egdels.github.io/makeacopy/privacy).
