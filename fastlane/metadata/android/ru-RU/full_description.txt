MakeACopy — это приложение для сканирования документов с открытым исходным кодом для Android, которое позволяет оцифровывать бумажные документы с офлайн-функцией OCR. Приложение ориентировано на конфиденциальность и работает полностью офлайн — без подключения к облаку и без отслеживания.

Особенности:
-  Сканирование камерой: съемка документов с помощью камеры устройства  
-  Обнаружение краев: автоматическое определение границ документа с помощью OpenCV  
-  Коррекция перспективы: ручная или автоматическая настройка перспективы документа  
-  Экспорт в оттенках серого: опциональный фильтр при создании PDF  
-  OCR: офлайн-распознавание текста с использованием движка Tesseract с открытым исходным кодом  
-  Экспорт в PDF: сохранение отсканированных документов в виде поисковых PDF-файлов  
-  Поделиться и сохранить: локальный экспорт или обмен через другие приложения  
-  Темный режим: тема Material 3 с поддержкой светлого и темного режимов системы  
-  Ориентировано на конфиденциальность: полностью офлайн — данные не покидают ваше устройство

MakeACopy совместим с F-Droid и собирает нативные библиотеки OpenCV из исходников во время сборки, гарантируя, что в репозитории нет предсобранных бинарных файлов. Все компоненты с открытым исходным кодом и уважают вашу приватность.
